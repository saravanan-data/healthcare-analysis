Developed an end-to-end Healthcare Analytics solution to analyze patient demographics, chronic conditions, insurance coverage, and registration trends—delivered across Excel, SQL, Power BI, and Tableau.

Project Highlights
• Analyzed 10,000 patient records across 
  92 fields and 7 interconnected tables.
• Performed end-to-end data cleaning,
  transformation, and data modeling.
• Addressed key healthcare business
  questions using KPI cards,
  interactive filters and dashboards.
• Generated actionable insights into 
  patient demographics, 
  chronic conditions, insurance coverage, 
  and registration trends.
• Demonstrated cross-platform analytics 
  and visualization skills by implementing 
  the solution across Excel, SQL, Power BI, 
  and Tableau.
